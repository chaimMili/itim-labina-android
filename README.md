# אפליקציית לוח שנה עברי וזמני היום - שיטת "עיתים לבינה" (Android Native + Glance Widget)

פרויקט אנדרואיד מלא ב-Kotlin (Jetpack Compose + KosherJava + Jetpack Glance) הכולל:
1. **זמני היום לפי שיטת "עיתים לבינה"** (כולל התחשבות בגובה טופוגרפי, עלות השחר 16.1°, משיכיר 11.5°, הנץ החמה במישור ובגובה העיר, סזק"ש ותפילה מג"א וגר"א, חצות, מנחה, פלג המנחה, שקיעה וצאת הכוכבים).
2. **איתור מיקום אוטומטי ב-GPS (כולל גובה)** או בחירה ידנית מערי ישראל.
3. **מערכת התראות חכמה (`AlarmManager`)** עם בחירה לכל זמן כמה דקות מראש להתריע.
4. **ווידג'ט לוח שנה עברי חודשי אינטראקטיבי למסך הבית (`Jetpack Glance`)** עם דפדוף בין חודשים והצגת זמני היום לכל תאריך שנבחר על גבי הווידג'ט.

## איך להפיק קובץ APK להתקנה בטלפון?

### אפשרות 1: הפקה אוטומטית בענן דרך GitHub Actions (ללא התקנת Android Studio במחשב)
בפרויקט זה מוגדר קובץ אוטומציה מוכן (`.github/workflows/build-apk.yml`):
1. העלה את תיקיית הפרויקט ל-Repository חדש בחשבון ה-GitHub שלך.
2. היכנס ללשונית **Actions** ב-GitHub.
3. תראה תהליך בשם **Build Itim LaBina APK** רץ אוטומטית (אורכו כ-2 דקות).
4. בסיום הריצה, לחץ עליו והורד מתחת ל-**Artifacts** את הקובץ **`ItimLaBina-Zmanim-APK`** שמכיל את ה-`app-debug.apk` המוכן להתקנה בטלפון!

### אפשרות 2: בנייה מקומית ב-Mac / PC
אם מותקן אצלך Android Studio או Android SDK:
```bash
# פתיחה ב-Android Studio ולחיצה על Build -> Build Bundle(s) / APK(s) -> Build APK(s)
```
הקובץ ייווצר בנתיב:
`app/build/outputs/apk/debug/app-debug.apk`
